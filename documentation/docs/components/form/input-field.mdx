# InputField Component

The `<InputField>` component is a versatile React component that provides various styling and functional options for text input fields. It supports icons, validation states, and different input styles.

## Basic Usage

All of the `React.CSSProperties` are valid props with the benefit of passing just the number without unit (`px` are used by default). The library extends the CSS properties and adds all of them with `Hover` suffix that will take effect only when the component is hovered by the device pointer.

<Tabs>

      ```jsx
      import { InputField } from "react-better-html";

      function App() {
         return (
            // highlight-start
            <InputField
               label="Username"
               placeholder="Enter your username"

            // highlight-end
         );
      ```

## Common Props

All standard `<input>` attributes are valid props for this component.

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      <InputField
         label="Username"
         placeholder="Enter your username"
         required
         disabled
         maxLength={50}
         onChange={(event) => {
            console.log("Input value:", event.target.value);
         }}
      />
   );
}
```

### Value change

The library provides a new onChange event called `onChangeValue` that is of type `(value: string) => void`.

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      <InputField
         label="Username"
         placeholder="Enter your username"
         // highlight-start
         onChangeValue={(value) => {
            console.log("Input value:", value);
         }}
         // highlight-end
      />
   );
}
```

:::note
Keep in mind that `onChange` and `onChangeValue` will both fire if passed.
:::

### Icons

The component supports both left and right icons:

- **`leftIcon`** - Icon name to display on the left side of the input
- **`rightIcon`** - Icon name to display on the right side of the input
- **`onClickRightIcon`** - Callback function when the right icon is clicked

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      <InputField
         label="Username"
         placeholder="Username..."
         // highlight-start
         leftIcon="user"
         rightIcon="XMark"
         onClickRightIcon={() => {
            console.log("Right icon clicked");
         }}
         // highlight-end
      />
   );
}
```

### Prefix and Suffix

The `prefix` and `suffix` props render an element attached to the left or the right side of the input. Their background can be changed with `prefixBackgroundColor` and `suffixBackgroundColor`.

<Tabs>
   <TabItem value="prefix" label="Prefix" default>

      ```jsx
      import { InputField } from "react-better-html";

      function App() {
         return (
            <InputField
               label="Website"
               placeholder="example.com"
               // highlight-next-line
               prefix="https://"
            />
         );
      }
      ```

   </TabItem>

   <TabItem value="suffix" label="Suffix">

      ```jsx
         return (
      ```

:::tip
For elements rendered inside the input field holder (e.g. a custom dropdown) use `insideInputFieldBeforeComponent` and `insideInputFieldAfterComponent`. The holder element can be accessed with `holderRef`.
:::

### Validation States

The component supports various validation states:

- **`errorText`** - Text to display when there's an error
- **`infoText`** - Text to display as additional information
- **`infoTextColor`** - The color of the info text
- **`required`** - Whether the field is required or not

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      <InputField
         label="Username"
         placeholder="Enter your username"
         // highlight-start
         required
         errorText="Please enter a valid username"
         // highlight-end
      />
   );
}
```

### Label

The label can be customized with the following props:

- **`labelColor`**, **`labelFontSize`**, **`labelFontFamily`**, **`labelLetterSpacing`**, **`labelTextTransform`** - the style of the label
- **`labelGap`** - the space between the label and the input

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      <InputField
         label="Username"
         // highlight-start
         labelFontSize={12}
         labelTextTransform="uppercase"
         labelLetterSpacing={1}
         // highlight-end
      />
   );
}
```

### With Debounce

The prop `withDebounce` is required to turn on that feature. When `true`, the `onChangeValue` event will be called with a delay (debounce). You can change the delay by passing the `debounceDelay` prop. The default value for it is `0.5s` and it works for the most part.

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      <InputField
         label="Address"
         placeholder="Enter your address"
         // highlight-start
         withDebounce
         onChangeValue={(value) => {
            console.log("Searched address:", value); // Will fire ones after the user stops typing
         }}
         // highlight-end
      />
   );
}
```

## Subcomponents

A number of components in the library have a _subcomponent_ feature witch is like a preset of the same component that is frequently used.

### InputField.multiline

This component renders a `<textarea>` component instead of `<input>`.

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      // highlight-start
      <InputField.multiline label="Description" placeholder="Enter your description" />
      // highlight-end
   );
}
```

```jsx
}
```

### InputField.phoneNumber

This component renders an input field with dropdown to pick the country code. Local country code is preselected by default.

```jsx

function App() {
   return (

         }}
      />

```

### InputField.date

This component renders an input field with calendar to pick a date. The value is in `YYYY-MM-DD` format.

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      // highlight-next-line
      <InputField.date
         // highlight-start
         minDate={new Date()}
         dropdownPosition="right"
         // highlight-end
         onChangeValue={(value) => {
            console.log("Ready date:", value);
         }}
      />
   );
}
```

- **`minDate`** / **`maxDate`** - the range of dates that can be picked
- **`dropdownPosition`** - align the calendar to the `left` (default) or to the `right` side of the field

:::note
On iOS Safari the native date picker is used.
:::

### InputField.time

This component renders an input field with time picker to pick a time. The value is in `HH:mm` format.

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      // highlight-next-line
      <InputField.time
         // highlight-start
         minTime="09:00"
         maxTime="18:00"
         minutesToRender={[0, 15, 30, 45]}
         // highlight-end
         onChangeValue={(value) => {
            console.log("Ready time:", value);
         }}
      />
   );
}
```

- **`minTime`** / **`maxTime`** - the range of time that can be picked (defaults to `00:00` - `23:59`)
- **`hoursToRender`** / **`minutesToRender`** - the hours and minutes rendered in the picker
- **`dropdownPosition`** - align the picker to the `left` (default) or to the `right` side of the field

### InputField.dateTime

This component renders an input field with calendar and time picker to pick a date and time.

```jsx
import { InputField } from "react-better-html";

function App() {
   return (
      // highlight-next-line
      <InputField.dateTime
         // highlight-start
         minutesToRender={[0, 30]}
         defaultTimeAfterDatePick="09:00"
         // highlight-end
         onChangeValue={(value) => {
            console.log("Ready date and time:", value);
         }}
      />
   );
}
```

- **`minDate`** / **`maxDate`** - the range of dates that can be picked
- **`hoursToRender`** / **`minutesToRender`** - the hours and minutes rendered in the picker
- **`defaultTimeAfterDatePick`** - the time that is set when only a date is picked (defaults to `00:00`)
- **`defaultDateAfterTimePick`** - the date that is set when only a time is picked (defaults to today)
- **`dropdownPosition`** - align the picker to the `left` (default) or to the `right` side of the field
