## `isMobileDevice`

Returns a boolean based on if the environment is on a mobile device or desktop.

:::tip
Will detect if browser dev tools are opened and Device Toolbar is on.
:::

## `getBrowser`

Returns a string value of type `BrowserName` based on the environment the app is in.

```ts
export type BrowserName = "firefox" | "chrome" | "safari" | "edge" | "opera";
```

## `countries`

A list of all countries. It is used by [`<Dropdown.countries>`](../components/form/dropdown#dropdowncountries) and [`<InputField.phoneNumber>`](../components/form/input-field#inputfieldphonenumber).

```ts
type Country = {
   code: string; // "BG"
   name: string; // "Bulgaria"
   timeZone: string;
   phoneNumberExtension: string; // "359"
   phoneNumberFormat?: string;
};
```
